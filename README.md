# Classification-knn-classifier-decision-tree-and-logistic-regression-
In this project, classification techniques were applied to predict the type of wine based on its chemical properties such as acidity, alcohol content, density, sulphates, and sugar levels. Exploratory Data Analysis (EDA) was performed to understand the dataset, identified feature distributions, and detect outliers. The categorical target column was encoded using Label Encoding, followed by feature scaling for better model performance. Three classification algorithms — KNN, Decision Tree, and Logistic Regression — were trained and evaluated using metrics like accuracy, confusion matrix, classification report, and ROC-AUC score. The models achieved very high prediction accuracy, showing that the chemical characteristics of wine are highly effective in distinguishing between red and white wine samples.
